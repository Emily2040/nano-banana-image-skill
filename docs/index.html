This repository packages a production-ready image skill for Gemini’s Nano Banana image models. It interviews with restraint, grounds the scene, routes style intelligently, preserves identity during edits, and emits clean runtime JSON for downstream apps or agents.

In the repository root, the canonical files are SKILL.md, README.md, AGENTS.md, CLAUDE.md, and GEMINI.md.

What the skill actually does

It is not just “prompt tips.” It is a full workflow spine with modular files for interviewing, grounding, preservation, typography, style routing, and runtime handoff.

Interview

Ask less, get more

Collect only the missing high-value constraints. No bureaucratic questionnaire cosplay.

Grounding

Reality before ornament

Anchor era, geography, materials, props, and world logic so scenes behave coherently.

Preservation

Edits with memory

Lock geometry, crop, identity, and labels before describing changes, so edits stay surgical.

Compiler

Prompt + JSON

Emit readable prompts and validated runtime payloads instead of improvised blob-text.

Compatibility strategy

Different agent ecosystems discover instructions differently, so the repo carries multiple entrypoints without duplicating the real logic.

AGENTS-style project guidance AGENTS.md Points the agent to the canonical skill and repo workflow.
Claude Code memory CLAUDE.md Loads concise repo-specific memory without replacing the skill.
Gemini CLI memory GEMINI.md Imports the canonical skill and references supporting files.

Install patterns

The repository is structured so you can clone it as-is, symlink it, or drop it into a project-local skills folder.

Codex / skill-aware clients 
mkdir -p ~/.agents/skills
ln -s /path/to/nano-banana-image-skill   ~/.agents/skills/nano-banana-image-skill
Claude Code 
mkdir -p ~/.claude/skills
cp -R nano-banana-image-skill   ~/.claude/skills/
Gemini CLI 
# cleanest option
open the full repository as a workspace

# if transplanting memory,
# copy GEMINI.md + SKILL.md + referenced folders
GitHub Pages

Folder: /docs

Validation + CI

The pack ships with scripts/validate_repo.py, a runtime compiler script, and a GitHub Actions workflow. That makes it much harder for quiet schema drift to sneak in and wreck the examples like a raccoon in a pantry. 

python scripts/validate_repo.py
python scripts/compile_runtime.py   examples/authoring/poster-edo-festival-text.json   -o /tmp/poster.runtime.json
